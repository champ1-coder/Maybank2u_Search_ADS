How to use this mock: tap the filter pill on either phone to switch between Transaction History / Debit Card History / M2U History / Bill Payment / Fund Transfer / WU Transfer Status — the same filters from the real MAE app. The left (baseline) phone recreates today's behaviour: every filter tap re-scans the full list and shows a ~3 second loading spinner before sorting the results newest-first, and there is no way to search. The right (optimized) phone has the same filters but they resolve instantly (HashMap lookup, no loading spinner), plus a search bar that queries the same index by merchant, amount, or reference number and returns results already sorted (AVL Tree traversal, no sort step). Both phones are seeded with the same ~180 synthetic transactions, including a handful of "Shopee" purchases buried among many M2U entries, to demonstrate the scrolling problem described in the report.
